# Repository Rules

- The user will provide the PDF assignment and the corresponding session materials. Read both before implementing and follow their requirements.
- Use `Sesiones/` as reference material for assignment statements, examples, and resources for each session.
- Save requested work in `Practicas/SX/`, where `X` is the session number. Create the practice folder if it does not exist.
- Do not develop submissions inside `Sesiones/` or a `bloque4` folder; neither is the destination for the work.
- Reuse the repository's existing `venv/` virtual environment and `.env` file when running exercises. Do not create or replace environments or credential files.
- Never copy, print, or include secret values from `.env` in files, responses, or debug output.
- Keep changes focused on the requested practice and preserve unrelated user changes.
- Validate changes with relevant checks using the existing environment, and report any tests that could not be run.
